Duplicate Files

Scan indexed library files, then review exact copies before deleting any. Exact copies are compared by SHA-256; different or unverified files for the same issue are listed separately. A filename ending in “(1)” alone does not prove a duplicate. Rescan a volume first if files were added outside Kapowarr.

Find the volume ID in its Kapowarr page address. Large scans are limited; select one volume if the report is incomplete. For exact groups, choose a copy to keep, check the copies to delete, then confirm. Nothing is automatically selected for deletion. For different or unverified editions, inspect the files and explicitly choose Keep before deleting any. Format and size do not prove which edition is better.
