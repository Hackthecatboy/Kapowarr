# Appearance and library navigation

Use the **Theme** selector in the header, or Settings → General → Theme, to choose
Light, Dark gray or Black. Changes apply immediately and are saved in the current
browser. A theme cookie also lets subsequent pages render with the chosen palette.

With the library sorted by **Title**, the right-hand **# / A–Z** rail jumps to the
first matching title in the current search/filter results. It works with Posters,
Table and mass editing. Missing letters are disabled; numbers and symbols use #.
Accented Latin initials use their base letter. Titles retain their leading words
(for example, The Amazing Spider-Man is under T). Other sorting modes hide the rail.

To check: switch themes, refresh, and navigate between pages. Try letter jumps in
both library views, then filter/search and verify unavailable letters are disabled.
Switch to Year sorting and confirm the rail disappears without changing the sort.
